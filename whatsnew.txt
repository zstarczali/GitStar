GitStar - What's new
====================

1.0.4
-----
- About: link to the website (www.c64va.pro/gitstar.html).
- Fix: Paste in the right-click menu of a text field (for example the
  commit message) asked for permission to read the clipboard. The text
  is now read by the app itself, without the prompt.

1.0.3
-----
- Settings dialog split into tabs: Git, SSH / Authentication,
  Appearance, AI and Update. The last used tab is remembered; switching
  tabs no longer resizes the dialog or shifts the tab row.
- New "Other branch..." button in the commit box: moves the uncommitted
  changes to an existing or new branch and commits the staged files there
  (for work done on the wrong branch). Clashing changes are carried over
  in a stash (pop --index); on conflict the stash is kept. Optionally
  switches back to the original branch afterwards.
- Update server: the bare server address (https://www.c64va.pro/) is
  enough, the downloads/GitStar/ folder is appended. A full folder
  address still works.
- Fix: the AI message button disappeared on hover in the light and
  retro themes.
- Fix: the Settings dialog jumped when the Git version check finished.

1.0.2
-----
- Clone dialog: parent-folder picker, SSH/HTTPS selection for GitHub,
  repository-name inference, Fill paths from repository button and live
  clone URL/destination preview. Custom URLs can be kept unchanged.
- Settings > Git > Git root folder sets the default parent for clones.
- Fix clone destinations on macOS/Linux: paths are joined natively
  instead of inserting a Windows backslash. Validate folder names before
  cloning and separate Git clone options from the supplied URL.
- Disabled dialog actions also remain disabled when Enter is pressed.
- Updated README and installation guide with SID-Studio clone example.

- Per-remote SSH / HTTPS selector in Settings > Authentication and the
  remote context menu. Shows current Fetch/Push URLs and previews changes.
  Converts standard github.com URLs while preserving distinct push targets;
  rejects unsupported URLs before changing configuration.
- Explains that SSH keys apply to SSH URLs, while HTTPS uses saved Git
  credentials. Updated README and installation guide.
- Push/fetch/pull/clone no longer open inherited VS Code / other askpass
  prompts invisibly. Missing credentials fail with a Git error instead.
- Network Git operations stop after 120 seconds without console output;
  their helper processes are stopped too. Progress output resets the timer.
  After a timed-out push, check remote status before retrying.
- Fix macOS Rust warnings: Linux-only PathBuf import and Windows-only
  mutable command variable.

1.0.1
-----
- Repository tabs show a badge with the number of files with uncommitted
  changes. Conflicts turn the badge red. Hover for staged, unstaged, and
  conflict counts. The active repository is checked every five seconds
  while the app is in focus.
- The main-window Donate button appears after 10 minutes of foreground
  use. The timer pauses while the window is unfocused or hidden and
  resets each time GitStar starts.
- The donation option in the About dialog remains available at any time.

1.0.0
-----
- SSH keys: Settings → SSH. Choose the private key git uses for SSH
  remotes, generate a new Ed25519 key, copy the public key for
  GitHub/GitLab and test the connection. On macOS the ssh-agent of the
  login shell (1Password, ssh-add…) is used too. An SSH permission error
  shows a tip pointing there.
- Zoom: Ctrl + / Ctrl − / Ctrl 0 or Ctrl + mouse wheel (Cmd on macOS),
  also in Settings → Appearance; remembered between runs.
- Panel sizes are saved in the settings file (they were sometimes lost
  at exit), the window size and position are saved at once, not only at
  a clean exit.
- macOS: no File/View/Window/Help menu, only the application and Edit
  menus (Edit is needed for Cmd+C/V). No browser context menu anywhere:
  text fields and selected text get a Cut/Copy/Paste menu instead.
- macOS: dragging the mouse no longer selects the texts of the interface.
- Dialogs close only with their buttons or the × in their corner, not with
  Escape or a click beside them.
- Closing a repository tab asks first.
- The same error message is shown only once, not stacked.

0.3.3
-----
- AI through the Claude Code CLI: choose "Claude Code CLI" as AI provider
  in Settings and the AI features use your own Claude login (Pro/Max
  subscription), no API key needed.
- The About dialog is wider, so its buttons fit on macOS too.

0.3.2
-----
- Dropdown lists are drawn in the colours of the current theme in every
  theme: readable items and a clear highlight (they were grey on grey in
  Modern dark).

0.3.1
-----
- License: GitStar is freeware. Free to use, but copying and
  redistributing it is not allowed (see LICENSE). The Windows installer
  shows the license.
- Donate button (pink heart) in the toolbar and the About dialog: opens
  the donation page in the browser.
- Endless progress bar under the toolbar while Fetch, Pull, Push, commit,
  merge, clone and other git operations run.
- Native controls (number spinners, scrollbars) follow the dark themes.
- README with the GitStar logo, and this what's new file.

0.3.0
-----
- Self-update: GitStar looks for a new version at startup and from
  About > Check for updates, downloads the installer with a progress bar,
  installs it and restarts. Download folder and startup check in Settings.
- Push is a split button: the main part pushes right away, the small arrow
  (or right-click) opens the Push dialog.
- PR button: opens the new pull request page of GitHub, GitLab, Bitbucket,
  Azure DevOps or Gitea/Codeberg, pushing the branch first if needed.
- Branch fields are combo boxes that offer the existing branches and tags
  (Push, PR, New branch, Merge, New tag, Compare).
- Modern and Modern dark (frosted glass) themes. The toolbar theme button
  switches between plain dark and light; the other themes are in Settings.

0.2.0
-----
- Splash screen at startup.
- The main window remembers its size, position and maximized state.
- Retro (8-bit) theme.
- Installers for Windows x64/ARM64, macOS Apple Silicon/Intel and
  Linux x64 (.deb, .rpm, .AppImage), built by GitHub Actions.
- AI panel shows a summary only.
- About dialog with copyright.
- Resizable commit message box, compact notifications after operations.
- Push button badge with the number of unpushed commits; Pull remembers
  its mode instead of asking every time.
- Git name and email in Settings; amend with author reset.
- AI neon theme, DeepSeek as a second AI provider with a Test button,
  English and Hungarian interface.

0.1.0
-----
- First version: a Fork-style Git client built with Tauri 2 and Rust,
  running git.exe for every operation.
- Local changes with stage/unstage/discard by file, hunk or line.
- Commit graph, history, search, blame, file history.
- Side-by-side and unified diffs with word-level highlighting, image diff.
- Branches, remotes, tags, stashes, merge, rebase, cherry-pick, reset.
- AI commit messages and AI diff analysis (Anthropic Claude).
